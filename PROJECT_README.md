# Business Entity Resolution Challenge

## Project

Large-scale business entity resolution across Source 1, Source 2 and Source 3.

## Pipeline

1. Dataset audit
2. Validation scorer
3. Normalization
4. Hybrid blocking
5. Candidate reduction
6. Pairwise features
7. LightGBM matching
8. Calibration and decision layer
9. Optional bi-encoder retrieval
10. Optional cross-encoder stacking
11. Final prediction
12. Submission validation
